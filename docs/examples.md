# Examples

Examples live in the repository as [marimo](https://marimo.io) notebooks under [`examples/`](https://github.com/kfreisen/mlb-dfs-solver/tree/main/examples). They are plain Python files, so they are linted and reviewed like the rest of the code.

CI executes every one of them on each change, which is what stops an example from quietly becoming documentation that no longer runs.

Rendered notebooks are published alongside these pages.
